# 〈師說〉3D 密室逃脫：搶救韓愈的原稿

學生在第一人稱的「昌黎書房」裡找出八個機關，依序解開〈師說〉的謎題，最後打開書房的門。

- 線上網址：https://nowel8577-code.github.io/nowel-tools/tools/shishuo-escape/
- 表單備案：開始畫面下方有「改用表單版」連結
- 時間：分組 15～25 分鐘；手機、平板、電腦都能玩，不需登入

## 八個機關

| 順序 | 機關 | 考點 | 答案 |
|---|---|---|---|
| 1 | 書櫃 | 師的三項職責 | 傳道、受業、解惑 |
| 2 | 天平 | 擇師標準 | 懂得道理（道之所存） |
| 3 | 屏風 | 誰「恥學於師」 | 今之眾人、士大夫之族 |
| 4 | 硯台 | 士大夫的藉口 | 羞、諛 |
| 5 | 畫像 | 孔子的四位老師 | 郯子＝古代官名、萇弘＝樂、師襄＝琴、老聃＝禮 |
| 6 | 竹簡 | 「師」的詞性 | 名、動、動、名 |
| 7 | 信封 | 寫作對象 | 李蟠 |
| 8 | 書匣 | 全文結論 | 先後、專攻 |

通關暗號：道之所存，師之所存也。

## 檔案

- `index.html`：頁面與介面
- `game.js`：打包後的遊戲（含 three.js 0.160.0），可直接雙擊 `index.html` 離線玩
- `src/`：原始碼。修改後用 esbuild 重新打包：
  `npx esbuild src/game.js --bundle --minify --format=iife --target=es2019 --outfile=game.js`
  （需先 `npm i three@0.160.0`）

場景全部用程式產生，沒有外部模型、圖片或音檔；音效用 WebAudio 合成。
進度存在瀏覽器 localStorage（鍵 `shishuo-escape-v1`），只記組別、關卡、時間、答錯與提示次數，不收個資。
